# Description: asgi.py

## Overview
Exposes the initialized FastAPI application instance `app` as an ASGI standard interface for production app runners like Uvicorn, Gunicorn, Render, and Vercel.

## Exports & Variables
- `app: FastAPI`: Fully wired FastAPI application instance generated by `create_app()`.

## Dependencies & Data Flow
- **Imports**: `create_app.create_app`.
- **Invoked By**: Production ASGI runners (`uvicorn asgi:app`, `gunicorn -k uvicorn.workers.UvicornWorker asgi:app`), Render Web Services, and Vercel serverless adapters.
- **Data Flow**: HTTP requests -> ASGI server -> `app` instance.
